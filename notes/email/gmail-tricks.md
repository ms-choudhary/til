
# Gmail Tricks

### Plus trick

You can create custom email address with plus sign to classify senders and create blocks. For eg, 

```
ms.choudhary+netflix@gmail.com
```

Some websites block this. 

### Dot trick

You can have any number of dots in the email address, for cases, where plus is blocked.

```
m.s.choud.hary@gmail.com
```
