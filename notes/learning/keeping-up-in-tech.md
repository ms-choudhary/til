# Keeping up in tech
### Learning pipeline

- Explore blogs, articles, talks for finding new stuff
- Find resources to learn specific thing [Learning Prompt](/notes/claude-code/claude-code-workflow.md#Learning)
- Filter the resources by quality
- Put the resources in right sequence
- Integrate everything
### Time management

Exploring, planning & doing each require different mindset. It's better to schedule a separate time for each of these. 

### Breadth vs Depth

Diving too deep in a topic has diminishing returns after a point. Also things get outdated quickly in the dynamic tech landscape. 

![](/_images/skill-knowledge-levels.png)

It should be like letter 'T'. You should know a lot of topics at high level, which you can easily pick up if required. And pick one or two silos in which you'll specialise and dive deep. 

Focus should more be on computer science fundamentals rather than tools and libs which change quite frequently. 

### You cannot keep up

You'll never be able to keep up with all the things. So prioritise:

- Need to know
- Should know
- Nice to know
- Edge case (only applies in specific scenarios)
- Useless
